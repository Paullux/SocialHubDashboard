# ❓ FAQ

![Niveau](https://img.shields.io/badge/niveau-grand%20public-brightgreen)

**Social Hub est-il gratuit ?**
Oui, dans sa phase actuelle. Un modèle payant pour des fonctionnalités avancées est envisagé à terme (voir [Vision & roadmap](06-vision-roadmap.md)), mais rien n'est décidé ni actif aujourd'hui.

**Est-ce que Social Hub peut publier ou modifier mes vidéos ?**
Non, jamais. L'accès demandé à chaque plateforme est strictement en lecture — voir [Sécurité & vie privée](04-securite-vie-privee.md).

**Quelles plateformes sont supportées ?**
YouTube, TikTok et Instagram aujourd'hui. D'autres pourraient s'ajouter selon la demande.

**Mes données sont-elles partagées avec d'autres utilisateurs ?**
Non. Chaque compte Social Hub ne voit que ses propres statistiques.

**Puis-je supprimer mes données ?**
Oui, à tout moment, en un clic depuis les paramètres — voir [la page dédiée](https://social-hub.fr/delete-data).

**Le code est-il open source ?**
Le dépôt est public sur GitHub. Une licence et un modèle "open source + service hébergé" sont envisagés pour l'avenir du projet — voir [Vision & roadmap](06-vision-roadmap.md).

**Puis-je contribuer ?**
C'est encouragé une fois le projet suffisamment mûr pour accueillir des contributions externes. En attendant, une issue ou une suggestion sur le dépôt GitHub est toujours bienvenue.

**Où est hébergé Social Hub ?**
L'application tourne sur Vercel, la base de données sur Neon (PostgreSQL), dans un centre de données européen. Détails dans [Architecture](03-architecture.md).

**Pourquoi certaines connexions (YouTube/TikTok/Instagram) affichent un avertissement "application non validée" ?**
C'est normal pendant la phase de vérification par chaque plateforme — voir [Intégrations API](05-integrations-api.md). Ça n'affecte ni la sécurité ni le fonctionnement pour un usage personnel.
